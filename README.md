
# 🏨 Hotel Booking System

A simple **Hotel Booking System** built using Python. This beginner-friendly project allows users to view rooms, book rooms, view bookings, search bookings, cancel bookings, and manage payment details.

## ✨ Features

- View available and booked rooms
- View room type and price
- Book a room
- Check room availability
- Store customer name and phone number
- Store number of guests
- Store check-in and check-out dates
- Calculate total room cost
- Support multiple-night bookings
- Add payment method
- Add payment status
- Search bookings using Booking ID
- Cancel a booking
- Exit the system

## 🛠️ Technologies Used

- Python
- Dictionaries
- Loops
- Conditional Statements
- User Input
- Exception Handling

## 🧮 Bill Calculation

The total room cost is calculated using:

```text
Total = Room Price × Number of Nights
````

Example:

```text
Room Price = Rs. 1800
Number of Nights = 3

Total = 1800 × 3
      = Rs. 5400
```

## 🚀 How to Run

1. Make sure Python is installed.
2. Clone the repository:

```bash
git clone https://github.com/siddhideshmukh15/python-hotel-booking-system.git
```

3. Open the project folder:

```bash
cd python-hotel-booking-system
```

4. Run the Python file:

```bash
python hotel-booking-system.py
```
