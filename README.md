
# Hotel Booking System#

A simple **Hotel Booking System** built using Python. This beginner-friendly project allows users to view rooms, book rooms, view bookings, and cancel bookings and search bookings.

## Features

- View available rooms
- View room type and price
- Book a room
- Check room availability
- View customer bookings
- Cancel a booking
- Exit the system

## Technologies Used

- Python
- Dictionaries
- Loops
- Conditional Statements
- User Input

## How to Run

1. Make sure Python is installed.
2. Open the project folder in the terminal.
3. Run the following command:

    python hotel_booking.py

## Concepts Learned

- Dictionaries
- while loop
- for loop
- if-elif-else statements
- User input
- Adding and deleting data
- Menu-driven programming
- Basic booking logic
